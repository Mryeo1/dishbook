## 翻译

如果你懂任何外语，你可以：
改进任何现有语言的翻译。

有关如何为 Tandoor 贡献翻译的更多信息，请参见[此处](/contribute/translations/)。

## 议题与功能请求

最基础但也最关键的贡献方式是报告议题，并在 [GitHub 议题](https://github.com/vabene1111/recipes/issues)上
对想法和功能请求发表评论。

没有反馈就不会有改进，所以不要犹豫，想说什么就说。

## 文档

帮助改进 Tandoor 的文档是最容易的回馈方式之一，甚至不需要深厚的技术知识。
你可以编写关于如何安装和配置 Tandoor 的指南，扩充我们非标准配置的仓库。
或者你可以编写使用 Tandoor 某些高级功能（例如身份验证或自动化）的操作指南。

有关如何为 Tandoor 添加文档的更多信息，请参见[此处](/contribute/documentation/)。


## 贡献代码

对于真正有雄心的人，你可以帮助编写代码来修复议题、添加额外功能，或使用 Tandoor 丰富的 API
编写自己的脚本，并与社区分享你的成果。

关于贡献特定类型功能的指南可以在[此处](/contribute/feature_contrib/featureguides/)找到

在编写任何代码之前，请务必查阅[贡献指南](/contribute/guidelines/)以及
[VSCode](/contribute/vscode) 或 [PyCharm](/contribute/pycharm) 的特定配置。
